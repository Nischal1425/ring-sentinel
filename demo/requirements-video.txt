# Dependencies for BUILDING THE PITCH VIDEO only.
#
# Deliberately kept out of the top-level requirements.txt. The detector itself
# needs numpy, scipy and scikit-learn and nothing else - no torch, no GNN
# framework, no LLM client - and that stays true. Everything here exists to
# render a video, and none of it is imported by anything under sentinel/.
#
#     pip install -r demo/requirements-video.txt
#
# Also needed, and NOT installable from pip:
#   * ffmpeg on PATH        (winget install Gyan.FFmpeg  /  apt install ffmpeg)
#   * Google Chrome         demo/make_video.py screenshots the HTML frames with
#                           headless Chrome; the path is set at the top of that
#                           file and may need changing on a non-Windows machine.
#
# Versions are what the shipped video was rendered with, on 2026-09-05.

manim==0.21.0            # the four animated scenes in demo/scenes.py
chatterbox-tts==0.1.7    # the narration; pulls torch + torchaudio itself
